# Лицензии и зависимости Viewery

Собственный код Viewery распространяется по [MIT](LICENSE). `scripts/Build-Release.ps1` создаёт пакет приложения без libmpv и FFmpeg. При первом запуске пункт «Установить медиакомпоненты» загружает их напрямую от поставщиков в `%LOCALAPPDATA%\Viewery\MediaTools`. Также поддерживаются файлы рядом с `Viewery.exe`.

`scripts/Get-MediaTools.ps1` проверяет зафиксированные SHA-256 архивов перед распаковкой и копированием. CI использует эти компоненты для интеграционных тестов, затем выпускает отдельный пакет приложения.

| Компонент | Как используется | Исходники и лицензия |
| --- | --- | --- |
| libmpv 0.42.0, Windows x64 | Динамическая загрузка `libmpv-2.dll` из каталога приложения или пользовательского каталога MediaTools. Скрипт выбирает архив `libmpv-v0.42.0-x86_64-w64-mingw32-lgpl.zip`, официальный LGPL-вариант Windows-сборки. | [Релиз и исходники mpv](https://github.com/mpv-player/mpv/releases/tag/v0.42.0), [правила лицензирования исходников mpv и зависимостей](https://github.com/mpv-player/mpv/blob/v0.42.0/Copyright), [LGPL версии 3](https://www.gnu.org/licenses/lgpl-3.0.html), [конфигурация CI](https://github.com/mpv-player/mpv/blob/v0.42.0/.github/workflows/build.yml). |
| FFmpeg 9.0.2 Essentials, Windows x64, сборка Gyan | Конвертер запускает отдельный процесс `ffmpeg.exe`. Флаг `-IncludeProbe` дополнительно устанавливает `ffprobe.exe` для проверок. Сборка использует `--enable-gpl --enable-version3` и сообщает лицензию GPL-3.0-or-later через `ffmpeg.exe -L`. | [Релиз Gyan](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2), [ревизия FFmpeg](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b), [лицензирование FFmpeg](https://ffmpeg.org/legal.html), [GPL версии 3](https://www.gnu.org/licenses/gpl-3.0.html). |
| nlohmann/json 3.12.0 | Встроенный исходный заголовок `src/third_party/json.hpp`, разбор метаданных и ответов GitHub. MIT-уведомление сохранено в заголовке и `src/third_party/json.LICENSE.MIT`; копия включается в пакет как `licenses/nlohmann-json.MIT.txt`. SHA-256 заголовка: `aaf127c04cb31c406e5b04a63f1ae89369fccde6d8fa7cdda1ed4f32dfc5de63`. | [Официальный релиз](https://github.com/nlohmann/json/releases/tag/v3.12.0), [MIT](https://github.com/nlohmann/json/blob/v3.12.0/LICENSE.MIT). |
| Windows SQLite (`winsqlite3.dll`) | Системная библиотека Windows 11, загружается из System32. Не копируется в пакет приложения. | [Windows SQLite API](https://learn.microsoft.com/en-us/windows/win32/winsqlite/winsqlite3-h), [SQLite public domain](https://sqlite.org/copyright.html). |

Если готовый пакет Viewery будет распространяться вместе с медиабиблиотеками или исполняемыми файлами, для точных сборок понадобятся применимые тексты лицензий, уведомления об авторских правах, соответствующие исходники и материалы сборки, включая исходники встроенных зависимостей. Для LGPL-сборки следует сохранить возможность заменить `libmpv-2.dll` ABI-совместимой версией.

Для текущего релиза соответствующие исходники встроенного JSON и код Viewery находятся в репозитории. Медиакомпоненты не включаются ни в portable ZIP, ни в полный MSIX. Цифровая подпись MSIX требует отдельного действительного сертификата издателя; файл без подписи обозначается `.unsigned.msix` и публикуется только как артефакт проверки упаковки.
