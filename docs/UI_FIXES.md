# Исправления интерфейса 0.2.0-beta.2

Панель Rename Studio теперь содержит неподвижные вкладки и кнопку закрытия, отдельную прокручиваемую форму и неподвижный статус. Прокрутка перемещает один контейнер с полным обновлением его области. Открытые выпадающие списки не перестраиваются при прокрутке.

В конструкторе показаны пресет, пример имени и список частей. Настройки зависят от выбранной части; префикс, суффикс, запасное значение, регистр и счётчики раскрываются отдельно. Изменения сразу видны в примере. Обычный клик выбирает часть, перетаскивание начинается после порога движения. Редкие действия с пресетами находятся в меню «···».

Кнопка «Переименовать» переключает видимость панели. «Закрыть» и Esc скрывают её, сохраняя модуль и данные. Первый Esc при открытом выпадающем списке закрывает список.

В каталоге чекбокс выбирает файл, клик по картинке открывает его, Ctrl/Shift меняют выделение. При просмотре другого файла выбранный набор сохраняется. Пустой набор в режиме чекбоксов остаётся пустым. ПКМ по миниатюре открывает меню конкретного файла, а параметры каталога доступны в заголовке и на свободном месте. Контекстное меню содержит просмотр, расположение, копирование файла/пути/имени, выделение, переименование и свойства.

Исправлены размеры заголовка и нижней строки, отступы списка с чекбоксами, расположение поиска при нижнем каталоге и обработка колеса над правой панелью. Колесо над инструментами не меняет громкость и масштаб медиа.

## Проверка

Чистая сборка Release на Windows 11 x64 прошла без предупреждений `/W4`. Итоговый CTest: **9 из 9 прошли, пропусков нет**, 18,92 с. В тесте Studio — 549 утверждений, в тесте основного окна — 33. Оба GUI-теста включены в Windows CI и релизную сборку.

Нативный тест панели использует production manifest с Common Controls v6, отдельный рабочий стол и временную базу. Проверены 72 сочетания: ширина 380/510 dp, высота 340/460/700 dp, DPI 96/120/144 и четыре вкладки. Во всех случаях пиксели панели после прокрутки туда и обратно совпали с исходными; сравнивались настоящие backing pixels окна. Дополнительно проверены раскрытие/выбор пресета, клик и перетаскивание частей, автоматическое обновление примера, устаревший предпросмотр, переименование, история и Undo. Снимки документации получены с этой тестовой панели.

Основной интерфейс отдельно проверен на независимость просмотра/выделения, закрытие панели без отключения модуля, размер 670 × 475, DPI 96/120/144, обработку колеса, границы поиска и выбор файла для ПКМ. В тесте меню перехватывается после построения: Windows Properties, Проводник и буфер обмена не вызываются автоматически.

Для запуска GUI-проверок включите `VIEWERY_GUI_TESTS`. В окружении, запрещающем отдельный рабочий стол, тесты возвращают код 77 и отмечаются CTest как пропущенные. Пользовательские окна, настройки и база не используются. Схема базы и формат сохранённых пресетов не менялись.
